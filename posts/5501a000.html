Hello World | 博客创建与迭代记录(长线优化）

发表于2026-03-17|更新于2026-09-02|Hello World
|浏览量:

前言

2026年3月14日，对我是不平凡的一天：
这天参加了软件系统安全赛的初赛，打出一道隐写题，有道流量题差一分钟交Flag，痛失现场赛资格，赛后耿耿于怀，翻遍各大论坛找其他师傅的wp核对思路，未果，然后突发奇想：

“此时此刻，会不会也有一个人，也在埋头寻找那道杂项的wp呢”

正好wp截止时间已到，我就抱着试一试的心态，把wp上传到了CSDN上，反响意外的好，还被纳入了“最佳新人榜”（虽然含金量约等于“再来一瓶”）这对我而言是莫大的鼓舞。可CSDN漫天的广告弹屏，莫名的删评审核，以及逆天的会员推送，无不在劝退着我，而本人撰写博客的热情刚被激起，又怎能善罢甘休，这时，我突然想起Himekawa学长分享过的个人博客，一个想法闪过心头：
——我也要创建独立博客!

说干就干，我以学长的博客为榜样，大致了解了Hexo和Butterfly的相关信息，经过广泛搜集教程和AI的指引，终于一砖一瓦地，搭好了这个小站，当 https://c01in-0.github.io/（旧域名）呈现在我的浏览器时，我突然想起七岁第一次拼成乐高的那个下午，当时的喜悦和成就感是何等强烈，韶华飞逝，岁月荏苒，如今展现在我眼前的，又是一个新的世界。

谨以此文，记录本博客的搭建和迭代历程，见证 Colin 迈向新世界的足迹。

Hello World

博客历程

2026.3.15


(此时的网站还叫 https://c01in-0.github.io/)

  1. 依托GitHub Pages 和 Hexo，搭建了该网站的框架；
  2. 在VScode修整了昨天比赛的wp，上传到本博客；
  3. 略微调整了页面的格式。

2026.3.16


(换了一个 30MB 的壁纸，然后给我卡爆了（)

  1. 在Namesilo上购置了新域名（c01in.com）；
  2. 将域名部署到 Cloudflare Pages，并且关联了GitHub Pages；
  3. 安装了Butterfly，设置了网页背景图，增添各类小组件（虽然还没添置功能），进行了一系列美化；
  4. 增添了GitHub的主页直达图标（只有点小图标能到达，点“Follow Me”不行，何意味）；
  5. 修复了点无功能组件会404的bug，现在会回弹到主页；
  6. 将背景图改为仓库链接，以使国内无网络代理用户能看到背景图（但是加载有点慢）。

2026.3.17


(看上去清爽多了)

  1. 优化了Cloudflare的部分设置，一定程度上提高了网页的加载速度；
  2. 开启Cloudflare的2FA认证，启用了Bot Fight Mode等安全防御；
    (Gemini: 你的博客又没数据库，加那么多防护干嘛)
  3. 开启了Always Online，以确保GitHub抽风时仍能访问镜像网站；
  4. 使用了新的壁纸，并利用Squoosh对其压缩，使其加载时不会有“刷漆感”；
  5. 修复了左上角Logo不显示的bug，并追加动态交互效果（鼠标移动到图标会放大），将logo背景设为透明以减少暗色模式的突兀感；
  6. 完善了“标签”和“友链”功能；
  7. 新增了“待办”组件，并填充其内容；
  8. 撰写《Hello World – 博客创建与迭代记录》并上传;
  9. 非常荣幸，与Himekawa学长互换了友链;
  10. 修复了点击“follow me”会到达莫名网址的bug，现在会导向个人的github主页;
  11. 修复了点击email回弹首页的bug，现在点击邮件会跳转发送邮件的平台，接受方为本人的邮箱。

2026.3.19

  1. 有幸连上了“一只枷锁”师傅的友链；
  2. 在首页增添了随机副标题（还埋了一个小彩蛋）；
  3. 修改了几处病句；
  4. 将各页面UI改为“毛玻璃”质感，并追加动态交互效果。

2026.3.20

  1. 修复了首页随机副标题的光标漂移与闪白Bug，实现无感加载；
  2. 为暗色UI增加“黑曜石玻璃”质感，配合视差滚动（Parallax）消除文章头图截断感；
  3. 优化待办清单与独立页面UI，将大板块设置为静态；
  4. 引入思源宋体与 Fira Code 编程字体，优化了代码的字体；
  5. 开启全局字体抗锯齿（Anti-aliasing），修复跨浏览器字体发虚的bug；
  6. 开启 Pjax 全站无刷新加载，提升切页流畅度；
  7. 调配全局光影与渐变暗角，修复进站“白屏”的问题；
  8. 修复图片异步加载导致右侧目录 (TOC) 偏移错位的问题。

2026.3.23

  1. 修复了edge浏览器ctrl+F5刷新后首页光标乱闪的问题。

2026.4.8

  1. 增添F12控制台小彩蛋；
  2. 增加搜索栏功能。

2026.4.12

  1. 更改了部分字体的颜色,优化其在当前背景下的可读性；
  2. 修复了搜索栏在上滑页面有概率发灰的Bug；
  3. 调整了博客文件结构,以便利用Obsidian撰写含图片博文；
  4. 引入了主页字幕延迟的Bug 😢。

2026.4.25

  1. 修复了主页字幕忽闪的Bug；
  2. 修复了“待办”页交互效果消失的Bug；
  3. 修复了暗色模式下交互效果会闪白的Bug；
  4. 引入了hexo-abbrlink 插件，用来精简分享链接。

2026.4.26

  1. 修复了主页字幕偶尔出现双光标的Bug；
  2. 在主页打字机的常驻词库和控制台中埋入小彩蛋，任意界面键入“prts”即可触发。

2026.4.27

  1. 对“PRTS”页面进行了一系列调整与“优化”。

2026.7.30

  1. 调整了鼠标光标移动到图片上的浮动效果，增加图片灯箱。

2026.8.10

  1. 重做“分类与标签”索引页：分类负责确定坐标，标签负责连接知识脉络，并加入可以聚焦、缩放和检索的知识星图；
  2. 重新梳理标签之间的关系，修复节点重叠、连线穿过标签以及父子层级混乱的问题——它终于不再像一团放在口袋里忘了收好的耳机线；
  3. 为知识索引补齐移动端分组列表、键盘操作和“减少动态效果”适配；
  4. 同步整理友链、待办与暗色模式的基础材质，减少偏绿、闪白和背景过脏的问题。

2026.8.11

  1. 将知识星图改为更明确的“上级—当前—下级”结构，父子关系使用实线，关联关系退到两侧，避免把“有关联”和“属于”混为一谈；
  2. 让父标签的文章数量包含其所有子标签文章，并固定右侧结果区高度，解决文章多时整个索引页忽大忽小的问题；
  3. 逐一检查知识星图中的全部标签，重新规划分支与共享主干，清理节点挤压、长线交叉和缩放后字体扭曲；
  4. 调整文章首屏、标题与正文的衔接，让正文更早进入视野；同时统一索引、友链、待办的字体、图标和移动端布局；
  5. 开始试验新的顶部应用栏：保留左右分布，放弃不太协调的居中命令坞，并把玻璃效果控制在不抢正文注意力的范围内。

2026.8.13

  1. 为右上应用栏加入低存在感的液态玻璃与局部折射效果，修复页面上滚时导航突然变成高亮白块的问题；
  2. 重做页面滑轨与滚动条：常态保持纤细可见，光标靠近右侧区域时再增强反差，不必再像找隐藏开关一样寻找它；
  3. 优化知识索引右栏的文章切换，快速划过标签时不再反复闪屏，并固定“知识星图”字体，避免缩放时忽大忽小；
  4. 让搜索、底栏、友链和待办在亮暗模式下使用更统一的中性玻璃材质，削弱突兀的大蓝框、黑底和刺眼悬停；
  5. 将关键字体、PJAX 与图标资源本地化，延后访问统计脚本，按需加载搜索数据，并为图片启用原生懒加载，降低冷启动时受外部网络波动影响的概率。

2026.8.14

  1. 继续压低暗色模式中目录高亮、工具按钮和卡片交互的亮度，保留定位感但不再晃眼；
  2. 友链连线改为“常态弱、悬停显”：平时不干扰阅读，光标或键盘聚焦到卡片时再显示当前关系；
  3. 缩短文章头图区并把正文整体上移，宽屏滚动后尽量保留完整标题，空间不足时安全省略，避免标题与应用栏互相顶住；
  4. 壁纸会先完成加载与解码，再从原有渐变底色自然显现，减少偶发的“刷漆感”；
  5. 为液态导航补上移动端、触控设备与减少动态效果的安全降级，漂亮归漂亮，不能拿可用性去换。

2026.8.17

  1. 收紧液态透镜的活动边界，取消鼠标交互时越出应用栏的明显椭圆拉伸，并将这套克制版液态应用栏设为桌面端默认效果；
  2. 整理导航、搜索、底栏和亮暗主题的材质参数，逐步收束多代样式，避免未来的我为了改一层透明度先进行 CSS 考古；
  3. 重新调整文章阅读层级：正文作为主层，右侧目录与小组件适当退后；代码块、引用块、圆角、阴影和行号对比保持统一；
  4. 对长短文章、亮暗模式、桌面与移动端、键盘操作和减少动态效果进行发布前回归检查，并建立精简备份与迁移清单，为这轮大更新收尾。
